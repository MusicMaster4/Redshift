# Security

Please do not publish a suspected vulnerability in a public issue.

Use GitHub's private vulnerability reporting for this repository. Include the affected platform, Redshift version, reproduction steps, and the impact you observed. Reports involving update verification, installer integrity, display restoration, or unintended privilege use are especially useful.

Redshift does not collect telemetry or upload schedules. Update requests are limited to release assets hosted under `github.com/MusicMaster4/Redshift`.
